## 行内公式

欧拉公式 $e^{i\pi} + 1 = 0$ 是数学中最美的等式之一。

质能方程 $E = mc^2$，勾股定理 $a^2 + b^2 = c^2$。

希腊字母：$\alpha$ $\beta$ $\gamma$ $\delta$ $\theta$ $\lambda$ $\mu$ $\pi$ $\sigma$ $\omega$ $\Gamma$ $\Delta$ $\Omega$

## 块级公式

$$\int_0^1 x^2 \, dx = \frac{1}{3}$$

$$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$$

$$\lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = e$$

$$\nabla \cdot \vec{E} = \frac{\rho}{\varepsilon_0}$$

$$f(x) = \begin{cases} x & x \geq 0 \\ -x & x < 0 \end{cases}$$

## 常见结构

| 写法 | 效果说明 |
| --- | --- |
| `x^2` `a_i` | 上标 / 下标 |
| `\frac{a}{b}` | 分式 |
| `\sqrt{x}` | 根号 |
| `\vec{F}` | 向量箭头 |
| `\mathbf{v}` | 粗体 |
| `\times` `\cdot` `\pm` `\leq` `\geq` `\neq` | 运算符 |
| `\to` `\Rightarrow` `\infty` `\partial` `\nabla` | 箭头与符号 |
